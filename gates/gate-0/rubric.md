# 小关卡 gate-0（起步小关卡）：评分标准

给导师和考官用。你自己也可以先读：知道要考什么，不算作弊，考的是你能不能自己做出来、讲出来。

## 这一场考什么

- **实操题 4 道**：第 0.1、0.2、0.3、0.4 课每课抽一道，在练习场里现搭，名字和数字每次随机，没有提示。由工具批改。
- **讲解题和排错题**：实操题都通过以后（工具会提醒），在平时上课的对话里对导师说“请问我 gate-0 的讲解题”，导师来问；实操题批改过一场以后也可以先考讲解题，记下的“通过”会留着。也可以用 `examiner-prompt.md` 请一位考官。
- **用时**：实操题看抽到哪几道，加起来约 19～23 分钟（开考时工具会打印题数和预计用时）；讲解题和排错题约 10 分钟。它在第 0.4 课第 3 站的备份之后，是单独的一段时间。

## 怎样算过

- 实操：每一课都有一道题通过（工具判）。没通过的题，下一场换另一套题面再考，只考没通过的。
- 讲解：标准表里标「必过」的三条都够了，导师或考官判「通过」。然后由你自己运行 `python3 tools/course.py exam gate-0 --explain pass`；没过是 `--explain again`，过几天换一种问法再讲。
- 两样都做到，gate-0 才算过。没过也不挡下一课：工具会一直列出还没过的部分。第 0.4 课第 3 站的检查只要求 gate-0 有成绩记录。

## 讲解题

第一次用问法 A；上次记为 `again` 的，用问法 B。一道问完、等学习者答完，再问下一道。问的时候不提示，评的时候不教。

### 讲解题 1：备份

- 问法 A：为什么备份要放到第二个地方，并且要用 `zip -T` 确认它是好的，而不是在原来的文件夹旁边复制一份就算了？
- 问法 B：第 0.4 课你把学习工作区打包放进了「文稿」，还运行了 `zip -T`。假如只是在同一个文件夹里复制一份、也不检查，会出什么问题？
- **够了的回答里有**：(1) 放在同一个地方的两份会一起出事：删错、磁盘坏、同步把删除也同步过去，原件和备份一起没了；(2) 没检查过的备份可能是坏的或不完整的，真要用时才发现就晚了，`zip -T` 就是先试一下它能不能用。两点都要有，用自己的话说，不要求术语。
- **这样还不够**：只说“为了安全”“以防万一”，说不出防的是哪种出事；把 `zip -T` 说成“再压缩一次”或“加密”；只说“课文这么要求的”。

### 讲解题 2：完成的定义

- 问法 A：为什么一个任务要先写好「完成的定义」，而不是做到自己觉得差不多就算完成？
- 问法 B：看板上一张卡片要挪进「完成」栏之前，为什么要先对照完成的定义一条一条核对？
- **够了的回答里有**：(1) 完成的定义是写下来、能核对的条件，不是感觉：别人（或检查命令）照着它也能判断做没做完；(2) 没有它，“差不多”的任务会堆在看板上，看起来做了很多，其实哪件都没真做完，也不知道什么时候该停。
- **这样还不够**：只说“这样比较规范”“这样看起来整齐”；把完成的定义说成“截止日期”或“要做的任务清单”。

## 排错题

导师把下面一段贴给学习者（第一次用 A，补考用 B），请他答报错三问，再说怎么改。他只能读，不能先去运行。输出在 2026-11-19 的模拟环境里实际运行过（`/Users/你的用户名` 处是他自己的主文件夹）。

- **A**：他运行了 `python3 starter/hello-fx/conver.py`，看到：

  ```text
  python3: can't open file '/Users/你的用户名/Developer/fullstack-from-zero/starter/hello-fx/conver.py': [Errno 2] No such file or directory
  ```

  够了：谁在报错是 python3；关键词是 can't open file、No such file or directory（打不开文件、没有这个文件）；我刚才敲的文件名少了一个 t（`conver.py`）。改法：改成 `convert.py`，或者用 Tab 补全文件名。

- **B**：他运行了 `pyhton3 starter/hello-fx/convert.py`，看到：

  ```text
  zsh: command not found: pyhton3
  ```

  够了：谁在报错是 zsh（shell），不是 Python；关键词是 command not found（找不到这个命令）；我刚才敲的命令名拼错了（`pyhton3`）。改法：改成 `python3`。

- **两种都不够**：说“Python 没装好，要重装”“加上 sudo 再试”“电脑坏了”；三问里漏掉“谁在报错”。

## 没过以后

导师或考官最后给一张很短的练习清单：哪一课、哪一节、练什么（比如“第 0.4 课第 3 站：把『为什么要校验』用自己的话再写一遍”）。实操题没过的，下一场 `python3 tools/course.py exam gate-0` 只考那几道，换另一套题面。讲解题没过的，过几天用问法 B 再讲一次；排错题用另一种。
