# 从这里开始

> **核对日期** 2026-11-20（下面说的免费、版本和界面，都是这天核对的）

第一次只读「怎么拿到这门课」和「今天做什么」两节就能开始；别的部分以后用到再看。

这个文件夹叫 `fullstack-from-zero`，是你从零开始学全栈工程师的地方。全栈工程师就是从用户看得见的网页，到背后干活的程序，再到放上网，这一整条都做得下来的人。课文（每一课的文字说明）、自动检查你做得对不对的学习工具、你自己的笔记和日志，都放在这个文件夹里，所以它也叫**学习工作区**。教你的是 Claude：在这个文件夹里，它按这里的规则当**导师**，给提示、回答问题，不替你做练习。每学一样做法，课文都会告诉你它是哪一类规矩、谁定的、有多强制、哪天核对过。

## 怎么拿到这门课

已经有 `fullstack-from-zero` 这个文件夹的，跳过这一节。

这是一门公开的中文课程：Claude 当导师，一步步带你从零学全栈工程师。现在阶段 0 和阶段 1（20 课）可以学，后面的阶段只有大纲。

要准备三样：

- 一台 Mac。课文是在一台 Apple 芯片的 Mac（macOS 27）上核对的；系统更旧的，可能有几处和屏幕对不上，遇到了对导师说“课文对不上”。
- Claude 桌面应用。从官方页面 https://code.claude.com/docs/en/desktop-quickstart 下载 macOS 版，装好后从「应用程序」打开，用你的 Claude 账号登录（2026-11-21 核对）。
- 一个能用 Claude Code 的 Claude 账号。导师在桌面应用的 **Code** 标签里，它要 Pro、Max 这类付费方案，免费方案用不了。出处：Claude Code 官方文档 https://code.claude.com/docs/en/setup （2026-11-20 核对）。

下载课程：

1. 在这门课的 GitHub 页面上，点文件列表上方的 **Code** 按钮，再点 **Download ZIP**（下载压缩包）。
2. 双击下载好的压缩包，解压出一个文件夹，名字通常是 `fullstack-from-zero-main`，把最后的 `-main` 去掉，改名为 `fullstack-from-zero`。用 Safari 下载的，它多半已经替你解压好了，直接在「下载」文件夹里找这个文件夹。
3. 打开访达（Finder），按 ⇧⌘H 到你的主文件夹，在里面新建一个文件夹 `Developer`（已经有了就不用建），把 `fullstack-from-zero` 拖进去。

第一次在这台 Mac 上学，再装两样东西（Mac 上不一定有）。装软件由你自己动手，有看不懂的地方先问导师：

- **命令行开发者工具**：Apple 提供的一组命令行程序，`git` 和 `python3` 都在里面。打开「终端」App（在「应用程序」>「实用工具」里），敲 `git --version`，按回车。已经装好，会打印一行版本号；还没装，macOS 会弹出窗口请你安装，点 **Install**（安装），等它装完。出处：《Pro Git》第 1.5 节 https://git-scm.com/book/en/v2/Getting-Started-Installing-Git （2026-11-20 核对）。
- **VS Code**：课程用的编辑器。按官方说明，从 https://code.visualstudio.com/download 下载 macOS 版，打开下载好的 `.dmg` 文件，把 Visual Studio Code 拖进「应用程序」文件夹。装好以后打开 VS Code，按 ⇧⌘P 打开命令面板，输入 shell command，运行 **Shell Command: Install 'code' and optionally 'copilot' commands in PATH**；问要不要装 Copilot CLI 时选 No（这门课只用 `code`），再把终端关掉重开。出处：VS Code 文档「Installing Visual Studio Code on macOS」https://code.visualstudio.com/docs/setup/mac （2026-11-20 核对）。第 0.1 课第一次在终端里用 `code` 命令，到时候找不到它，对导师说“急救：code 命令找不到”。

为什么不用 `git clone`：克隆下来的文件夹带着这个公开仓库的历史和地址；第 1.12 课要把它变成你自己的私有仓库，到那时会对不上。下载压缩包不带历史，正好。出处：GitHub 帮助文档「Downloading source code archives」https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives （2026-11-20 核对）。

## 今天做什么

第一次坐下来，打开应用、选好文件夹大约 10 分钟，再开始第 0.1 课。

1. 打开 Claude 桌面应用，点上方的 **Code** 标签，再点左边栏的 **+ New**（新建对话）。〔对照文档，界面可能不同〕
2. 看输入框下面那一行：第一个按钮是运行环境，选 **Local**（在这台电脑上运行）；紧挨着它的是项目文件夹（project folder）按钮，点它，在菜单里选 **Open folder…**（打开文件夹），在弹出的窗口里选 `fullstack-from-zero` 这个文件夹本身，再点 **Open**（打开）。它在你的主文件夹（你这个用户在电脑上的“家”，写作 `~`）里的 `Developer` 里面，就是照「怎么拿到这门课」放的地方；放在别处的，选你当初放的那个。不要选它外面的那一层文件夹。
3. 在输入框里打下面四个字，按回车：

```text
开始上课
```

应用要是先弹出一个请求，问能不能让 Claude 运行 `python3 tools/course.py status`（课程的学习工具：查看进度，并记下今天学过），点允许。以后导师要运行别的命令时，也先看清它要做什么再点。〔对照文档，界面可能不同〕

和你看到的不一样？把屏幕上的内容发给导师，说“课文对不上”。

导师回你的第一行，固定以 `【教练模式】` 开头，叫**状态行**。第一次是这样：

```text
【教练模式】还没开始 · 说“开始上课”
```

学过一段以后是这样（阶段、第几课、上次学习的月和日）：

```text
【教练模式】阶段 1 · 第 6 课 · 上次学习 11-24
```

后面几个字可能略有不同，开头的 `【教练模式】` 不会变。有这一行，说明导师已经读了这个文件夹里的规则。

**没看到这一行**，多半是规则没加载，这时的 Claude 不会按教练的方式带你。按顺序试：

1. 看项目文件夹选的是不是 `fullstack-from-zero` 本身，选成外面那一层或别的文件夹就改过来。
2. 新开一个对话，再说一次“开始上课”。
3. 还是没有：先不等导师，自己打开第一课 `stages/00-orientation/01-first-steps/lesson.md` 往下学。课文里「跟我做」的部分不靠导师也能做完。把“状态行没出现”记进当天的日志，下次再处理。

## 一次学习长什么样

下面是第 0.1 课实际的走法，以后每次都一样：

1. **开场**：按上一节说“开始上课”。导师回状态行，然后替你打开课文和终端（用打字而不是点鼠标来指挥电脑的窗口）。没替你打开，就点对话最上面那排小图标里的 **Terminal**（终端）和 **Files**（文件）自己打开：鼠标停在小图标上会显示名字，找不到就点旁边的 **⋮**。还是没有：这些面板要 Claude 桌面应用 v1.2581.0 或更新，点屏幕顶上菜单栏的 **Claude** > **Check for Updates…**（检查更新）。〔对照文档，界面可能不同〕
2. **复习小题**：从第二次起，导师先请你做几道以前学过的小题。今天还没有；不想做可以说“跳过”。
3. **学一站**：一课分两三**站**，每站讲一样新东西。读「概念」，照「跟我做」在终端里敲命令，做「补全」，再「自己做」一道练习。命令敲在终端里那一行以 `%` 结尾的字后面，敲完按回车。
4. **检查**：做完练习，在终端里运行课文给的检查命令，比如 `python3 tools/course.py check 0.1a`。结果只有三种：通过；还没达标（告诉你看了哪里、缺什么，不给答案）；检查器出问题（工具的毛病，不是你的错，把那一段发给导师）。
5. **存档点**：每站结尾都是存档点，到这里可以放心停下。工具会打印下次该对导师说的那句话，比如“从 0.1b 继续”。
6. **收尾**：一课的几站都通过了，做三件事：全课检查；在 `notes/my-rules.md` 里用自己的话写下这一课的行规（这一课定下、以后一直要守的规矩）；用 `python3 tools/course.py journal` 写一句话日志：做了什么、卡在哪、下次从哪开始。
7. **下次**：开一个新对话，说“开始上课”，或者说工具上次打印的那句话。

每一站的标题里写着它大约要多少分钟。一次坐多久由你定，停在任何一个存档点都可以。阶段 0 和阶段 1 一共约 45 小时（阶段 0 约 8.5 小时，阶段 1 约 36.5 小时：各站标题里的分钟，加上每课的收尾和关卡，再加一成半留给复习；算式在两个阶段页面的「课表」下面）。整条路线有多长、每周花多少时间合适，见 `ROADMAP.md` 第 2 节。

导师有三种模式，说一句话就能换：**上课**（默认，导师当教练）；**干活**：你说“干活：<要做的事>”，它直接替你做，做完讲清做了什么，课程练习以外的事都可以这样请它做；**急救**：环境坏了、装不上东西、工具报“检查器出问题”，你说“急救：<一句话说现象>”，它先帮你修好。

## 卡住了怎么办

1. **先读屏幕。** 报错（程序告诉你哪里不对的那几行字）往往已经说了出了什么事。第 0.1 课第 2 站会教你用三个问题读它：谁在报错，关键词是什么，我刚才敲了什么。
2. **要一级提示。** 运行 `python3 tools/course.py hint <站号>`，比如 `hint 0.1a`。每运行一次多给一级，一共四级：方向、位置、相似的例子、答案和解释。
3. **把屏幕上的字原样发给导师。** 复制粘贴原文，不要凭记忆转述。环境坏了、工具报“检查器出问题”，就说“急救：<一句话说现象>”，再贴上去。
4. **十五分钟规则。** 同一处卡了十五分钟还没进展，就别硬扛，对导师说“直接告诉我答案”；到了十五分钟，导师自己也会提出给你答案或示范。导师按你在学习档案里定的严格程度处理：默认“适中”，先问一句“是累了，还是卡住了？”；“严格”先再给一级提示；“宽松”直接给。给了答案，都会请你用自己的话讲一遍，再做一个小变化。用到第四级提示的站，工具会安排你过三到七天不看提示再做一遍，这样答案才真正变成你的。
5. **课文对不上，或者导师的办法两次都不灵。** 前一种说“课文对不上”，导师会核对后改课文，改动记进 `CHANGELOG.md`；后一种说“换个思路”，请它先查官方文档再回答。还不行，就停在最近的存档点，把卡在哪写进日志，下次再来。

## 你需要准备什么

- **钱**：除了 Claude 的付费方案（见「怎么拿到这门课」），阶段 0 和阶段 1 不用另外花钱。导师在 Claude 桌面应用里，按你自己的 Claude 账号照常用。后面的阶段如果有要付费的东西，到时候会讲清价格和免费的替代办法，付不付由你决定（见 `ROADMAP.md` 第 2 节）。
- **软件**：课程要用 Claude 桌面应用、写代码的编辑器 VS Code、Python、Git（记录文件每一次改动的工具，第 1.6 课开始学）。Python 和 Git 跟着命令行开发者工具一起来，VS Code 要自己装（都见「怎么拿到这门课」）；装完还缺什么，运行 `python3 tools/course.py doctor` 会指出来。第 1.11 课还要用 Homebrew（一个装软件的工具）装 GitHub 的命令行工具 `gh`，免费，课里带你装。
- **账号**：第 1.11 课注册 GitHub（存放作品备份、也能展示作品的网站），免费，只要一个邮箱。课程要求你开双重验证，所以还要在手机上装一个验证器 App（每 30 秒变一次数字的小程序），GitHub 不指定是哪一个，有免费的。第 1.12 课起，你的学习记录在 GitHub 上有一份备份，放在**私有**仓库（被 Git 管着的文件夹）里，只有你看得到，免费；第 1.13 课你的网页放到网上时，网页那个仓库是公开的，也免费。
- **时间**：一周几次、一次多久，第一课的入学问卷会问你，课程照你的回答排。

## 搬家后怎么找回导师

> 这张卡片给在第 0.2 课请导师把课程搬到 `~/Developer` 的你（`~` 是你的主文件夹）。导师不在也能照着做。
>
> 1. **关掉旧的。** VS Code 里还开着旧文件夹的窗口，关掉。Claude 左边栏里以前的对话还连着旧的地方，以后不要再在里面继续。旧的那一份课程原样留着，里面有一个说明文件；不要在那里做练习。
> 2. **开一个新对话。** Claude 桌面应用 → **Code** 标签 → 左边栏 **+ New**。〔对照文档，界面可能不同〕
> 3. **选新的文件夹。** 输入框下面那一行，运行环境选 **Local**，再点旁边的项目文件夹按钮，在菜单里选 **Open folder…**。在弹出的窗口里同时按 Shift、Command、G 三个键，输入 `~/Developer/fullstack-from-zero`，按回车，再点 **Open**（打开）。〔建课时无法验证〕
> 4. **说这一句**：“开始上课”。
> 5. **看第一行。** 以 `【教练模式】` 开头，就是找回来了。再在终端面板里敲 `pwd`，按回车，输出的结尾应该是 `/Developer/fullstack-from-zero`。你的笔记、日志和进度都在这个文件夹里，已经一起过来了。
>
> **第一行不是 `【教练模式】`**：先看项目文件夹选的是不是 `Developer` 里的 `fullstack-from-zero`；再新开一个对话说“开始上课”。还是不行，在旧的那一份上打开 Claude，说“急救：搬家以后找不到新文件夹”，导师会带你找；在旧的那一份里只问路，不做练习。
>
> **没搬、只建了入口的你**（第 0.2 课选了“我先不搬，帮我在 ~/Developer 建一个入口”）：Claude 照旧在原来的 `fullstack-from-zero` 上打开（你最初放课程的那个地方）。课文里的 `cd ~/Developer/fullstack-from-zero` 经过入口，到的还是这个文件夹。

## 你可以放心的几件事

- **练习只在三个地方做**：学习工作区 `~/Developer/fullstack-from-zero`（没搬家的，就是那个入口通向的文件夹）、练习场 `~/Developer/playground`（工具搭出来给你随便折腾的地方）、你的网站 `~/Developer/my-site`（第 1.2 课建）。别的地方，只有你自己亲手、事先知道地动：第 0.4 课在 Documents（文稿）里放一个备份压缩包，第 1.6 课改 Git 的设置，第 1.11 课装 `gh`。这类改动整台电脑的命令都由你自己敲，导师不替你敲。
- **检查只看不改，也不联网。** 学习工具不改你写的文件。它只做三件事：把进度记在 `learner/` 里和 `PROGRESS.md` 里；你运行 `journal` 时，在当天的日志末尾添一条；在练习场里搭练习。唯一会上网的是 `python3 tools/course.py doctor --net`，只在你加了 `--net` 时才连一下 github.com。
- **没人替你提交或推送。** 提交是把改动存进 Git 的记录（第 1.6 课），推送是把记录传到 GitHub（第 1.12 课）。导师不替你做这两件事，除非你在当次对话里明说请它做。
- **你自己的文件不会被覆盖。** `notes/`、`journal/` 和 `learner/profile.md` 是你的；课程以后更新，也不会改它们。第 0.1 课你亲手改的 `starter/hello-fx/convert.py`，以后的课也不会换掉。

## 常见的担心

- **数学不好，学得会吗？** 阶段 0 和阶段 1 用不到数学；以后的阶段用到时，课里从头讲。
- **英文不好呢？** 前两个阶段里，你会碰到的每一句英文输出和报错，课文都在后面跟一句中文读法；入学问卷还会问你的英文程度。
- **年纪不小、打字慢呢？** 每站的分钟数是照“打字慢、第一次学”的人算的，标题里写的就是这个数；慢了不说明你不行，停在任何一个存档点都可以。
- **会不会把电脑弄坏？** 练习只在上面那三个地方做；会弄乱东西的练习都在练习场里，坏了用一条命令重建。
- **隔了很久没学，还能接上吗？** 能。对导师说“我回来了，带我走回归流程”：不考你，先花两分钟看你停在哪，做一个轻松的重做，再重新排这一周。

| `PROGRESS.md` | 你的进度表，学习工具生成的（第 0.4 课第一次生成），不要手改 |
| `stages/` | 课文：每个阶段一个文件夹，每课一个文件夹 |
| `handbook/` | 规范手册：所有行规的完整卡片，按类排好 |
| `gates/` | 小关卡和阶段验收的评分标准 |
| `cheatsheets/` | 速查表：终端、Git 这些常用命令一页看完 |
| `templates/` | 模板：每周复盘、求助提问、验收 AI 改动这些固定格式 |
| `notes/` | 你的笔记，比如 `notes/my-rules.md`：用你自己的话写的行规 |
| `journal/` | 你的学习日志，一天一个文件 |
| `learner/` | 你的学习档案和学习工具记的进度 |
| `starter/` | 练习用的起步材料：一个小程序和一个网页 |
| `tools/` | 学习工具：`python3 tools/course.py` 就在这里 |
| `docs/` | 建课的资料：设计、计划、调研记录，平时不用看 |
| `LICENSE`、`LICENSE-CC-BY-4.0.txt`、`LICENSE-MIT-0.txt` | 许可证：别人可以怎样使用这门课（见文末） |

还有两个名字以点开头、平时看不见的文件：`.gitignore`（告诉 Git 哪些文件不要记，第 1.9 课讲）和 `.editorconfig`（告诉编辑器文件统一怎么存，第 1.4 课讲）。

## 以后怎么拿到新课和改正

这门课以后会在 GitHub 上更新：加新的阶段，改课文里的错。下载的压缩包不会自己更新。想拿新版，就重新下载一份，但先别自己复制：把同名文件夹拖过去，访达会问你要不要“替换”，选了替换，整个旧文件夹就被换掉，你的记录可能跟着丢。对导师说“帮我合并新版课程”，导师会带你先做一份备份，再只更新课程的部分；`learner/`、`journal/`、`notes/` 这些你自己的记录不动。

原仓库还没有下一阶段、你又不想等的，可以在导师提醒你准备下一阶段时说“准备阶段 2”，让你电脑上的导师按 `docs/authoring/` 自己建。这要花很多次对话。两条路选了一条，以后想换另一条，先和导师商量怎么合并。
