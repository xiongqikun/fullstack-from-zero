# 阶段 9：交付与运维

> **规划用时** 100～140 小时 ｜ **前置** 阶段 8 ｜ **核实日期** 2026-11-19 ｜ 回到[路线图](../../ROADMAP.md)

下面是计划，建这个阶段时会按你的真实进度和当时的工具重新定。**这里是下车点三**：三个特别推荐的落脚点里的第三个。

## 目标

让看板在网上稳稳地一直运行。学会把程序连同运行环境装箱（行话叫容器：把程序和它要的一切打成一个包，搬到哪台服务器上都一样跑），让流水线（代码一推送就自动检查、自动上线的那套自动步骤）自动上线；学会看运行记录、设故障提醒、做备份、演练回退；算清成本。

## 作品

看板有了自己的网址，关了你的电脑它也在运行；出了问题你能发现、能退回上一版。比如服务停了，你的手机会收到一条提醒；一次改坏了，你用一条命令退回上一版，网址照样能打开。

## 技术清单（现在看不懂没关系）

- Linux 基础：SSH、权限、进程与信号、防火墙；systemd 只认识一下。
- Docker：镜像、容器、端口、卷；给 uv 项目写 Dockerfile、`.dockerignore`、多阶段构建、非 root 用户；Compose（现行是 v5）。
- 镜像仓库：GHCR。持续交付：GitHub Actions 的环境、密钥、OIDC、并发控制、上线后的冒烟测试。
- 平台：建课调研当天的建议是一个容器跑在托管平台上，数据库用托管的 PostgreSQL，另留一条不用绑卡的备选。价格和免费档到时重新核实。
- 数据库：迁移进流水线，先扩后缩（expand/contract）；`pg_dump` 备份与恢复演练。
- 可观测：JSON 日志、`/healthz` 与 `/readyz`、可用性监控、Sentry；OpenTelemetry 只演示。
- 域名与证书：DNS 记录（A、AAAA、CNAME、TXT）、TTL、Let's Encrypt 自动证书（ACME）、HSTS；Caddy 做反向代理。证书有效期逐步缩短：CA/Browser Forum 的 SC-081v3 决议。
- 回退：先用 `git revert` 向前修，重新部署上一个镜像当急刹车。
- 指标：DORA 的五项交付指标。
- 选做：租一台小服务器一周，自己装 Docker Compose 和 Caddy，用完删掉。
- 不进主线：Kubernetes、Terraform、多地区部署。
- 规则类型的出处：12factor.net；Docker 文档（non-root、secrets）；GitHub Actions 文档（environments、secrets）；CA/Browser Forum SC-081v3；Let's Encrypt / ACME（RFC 8555）；Google SRE book（postmortem culture）。
