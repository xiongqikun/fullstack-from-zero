# 阶段 7：现代前端

> **规划用时** 180～240 小时，和阶段 11 一起是全程最长的两个阶段 ｜ **前置** 阶段 6 ｜ **核实日期** 2026-11-19 ｜ 回到[路线图](../../ROADMAP.md)

下面是计划，建这个阶段时会按你的真实进度和当时的工具重新定。

## 目标

用现代前端的成套工具做一个完整的界面：先学 TypeScript（在 JavaScript 上加了一层检查的语言），再学 React（做网页界面的工具），加上配套的打包工具（把代码变成浏览器能用的成品）和测试工具。把阶段 3 那套规范在前端这边再做一遍。

## 作品

汇率看板的新界面。和阶段 6 那一页手写网页比，它是一个完整的应用：能切换币种和时间范围，有好几页，数据没回来时显示“加载中”，出错时有说法，没有数据时也有说法。打包之后由你的后端一并送出，用同一个网址打开。

界面连着你的后端跑通主要流程，有自动测试；阶段验收里有一道排错题和一道不用 AI 的小功能。

## 技术清单（现在看不懂没关系）

- 运行环境：Node.js 26 LTS 与 npm 11（建课时核对用的版本是 26.12.0 和 11.20.0）；`package.json`、lockfile、`npm ci`。
- 构建：Vite 8，`npm create vite@latest`。
- TypeScript 7：`strict`、联合类型与收窄、对象类型、轻量的泛型、给 DOM 和 `fetch` 标类型、`unknown` 加 zod 4 守住边界。
- React 19：组件、JSX、props、state 与事件、条件与列表渲染、状态上移、effects 放最后学。
- 应用层：React Router 8（声明式模式）、TanStack Query 5、表单加 zod、环境变量、开发代理。
- 质量：Prettier 加 Oxlint；Vitest 5 加 Testing Library；Playwright 做端到端测试。
- npm 安全：`min-release-age`、`allowScripts`、`npm audit`（对着官方源）。
- 交付：`vite build` 产出 `dist/`，由 FastAPI 的 `app.frontend()` 同源送出。
- 不进主线：Next.js 这类元框架、服务端渲染、Tailwind、Redux。
- 以上版本都是建课当天核实的。这一套在 2026 年 6 月到 11 月之间换了默认的检查工具和好几个大版本，学到时必须重新核实。
- 规则类型的出处：TypeScript 文档（`strict`）；npm 文档（`npm ci`、`min-release-age`、`allowScripts`）；OWASP ASVS 5.0.0；Testing Library guiding principles。
