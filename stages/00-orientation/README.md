# 阶段 0：起步

> **规划用时** 约 8.5 小时（4 课，12 站）｜ **前置** 无 ｜ **核实日期** 2026-11-19 ｜ 回到[路线图](../../ROADMAP.md)

一站是一段学习。每站的标题里写着它大约要多少分钟，是按一个打字慢的新手算出来的，最长 40 分钟。站的结尾是存档点：到那里可以放心停下，下次对导师说“从 0.1b 继续”这样的话，从下一站接着学。

## 目标

第一次学习的二十分钟左右，你就在终端（用打字而不是点鼠标来指挥电脑的窗口）里敲下命令，当天运行并改动一个小程序。然后弄清文件和路径（文件在电脑里的地址），给代码找好安家的地方，知道规范从哪来，给自己的学习定下计划。

## 作品

你的学习计划，和一个你亲手改过的小程序。

这个小程序叫 `hello-fx`，按固定汇率换算一笔钱。第一次运行时，终端里会出现这样一行：

```text
100 美元 ≈ 710.00 人民币（按 1 美元 = 7.10 人民币计算）
```

你会改掉里面的一个数，再运行一次，看结果跟着变。

它是贯穿全程那个产品的种子。默认的产品是汇率看板：一个显示汇率的网页。如果你已经有一个 AI 帮你做的作品，课程不改它的代码，而是带你从这个小程序开始，自己一块一块做出一个。第 0.3 课拿汇率看板当例子，拆开看一个真实的软件由哪几块组成：界面、后台程序、数据、运行环境（程序运行时离不开的那些软件和设置）。这一课里你也可以把产品换成别的题材。

## 过关方式

小关卡 gate-0（起步小关卡），在第 0.4 课第 3 站的备份之后。它是单独的一段时间，开考时工具会打印题数和预计用时。到时对导师说“做小关卡 gate-0”。

- **实操题**：第一场是四道不给提示的题，第 0.1 到 0.4 课每课一道，题目里的名字每次随机生成。做题时不问导师，也不用 AI。
- **讲解题**：实操题都过了，对导师说“请问我 gate-0 的讲解题”。导师问你几个问题（约 10 分钟）：请你讲出“为什么这样做”，再读懂一段报错。导师给出结论以后，你自己运行 `python3 tools/course.py exam gate-0 --explain pass` 记下来；导师说要再讲一次，就记 `--explain again`。
- **怎样算过**：这四课每课都有一道实操题通过，讲解题也记为通过。没过的题，下一场换一套题面再考，只考没过的那几道。
- 小关卡不挡下一课：没过也可以接着学第 1.1 课，工具会一直显示还有什么没过。
