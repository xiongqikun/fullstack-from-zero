## 第 1 站：认识学习界面和导师（约 40 分钟）

### 概念

每次学习，你面前有三样东西：

- **课文（lesson text）**：你正在读的这份文字，告诉你一步步做什么。
- **终端（terminal）**：用打字而不是点鼠标来指挥电脑的窗口。命令（command），也就是你敲给电脑的一行指令，都敲在这里。
- **导师（tutor）**：按这个文件夹里的规则当教练的 Claude。它给提示、回答问题，不替你做练习。

这三样都围着 `fullstack-from-zero` 这个文件夹转。它叫学习工作区（workspace）：课文、学习工具和你以后的笔记都在里面。

这像学开车：课文是教材，导师是副驾驶上的教练，终端是你亲手操作的那一部分，就像车要你自己开（终端本身像什么，下一站另有一个比方）。这个类比在一个地方不成立：印好的教材不会改，这里的课文会；课文和屏幕对不上，导师核实以后会改。

导师平时在上课，当教练；东西坏了，对它说“急救：<一句话说现象>”，它先帮你修；不是练习、想让它直接做的事，说“干活：<要做的事>”（第 1.15 课才用到）。

每一站的结尾是一个存档点（save point）：到那里可以放心停下，下次从下一站接着学。

## 第 2 站：终端三条命令（约 25 分钟）

### 概念

终端像一部对讲机：你说一句，它回一句。你敲一行命令，按回车，它把结果打出来，然后等你说下一句。

这个类比在一个地方不成立：对讲机那头是人，听错了会问你；终端不会猜你的意思，错一个字符它就不认。

它在等你的时候，行首有一段**提示符（prompt）**，大致是这样：

```text
你的用户名@你的电脑名 fullstack-from-zero %
```

从左往右：你的用户名、`@`、你的电脑名、你现在所在的文件夹，最后的 `%` 表示“请讲”。你只敲 `%` 后面的部分。课文里的命令都不带提示符，复制的时候也只复制命令本身。

### 跟我做

这一站在学习工作区里做，也就是提示符里显示 `fullstack-from-zero` 的地方。显示的不是它，看第 1 站第 3 步最后那一段。

#### 1. 我在哪：`pwd`

先猜一猜：一条叫“打印当前所在的文件夹”的命令，会打出什么样的一行？先说出猜想再看结果，猜错的地方最容易记住。

```zsh
pwd
```

你应该看到一行以 `/Users/你的用户名/` 开头、以 `/fullstack-from-zero` 结尾的路径。「你的会不一样」：中间那几段看你自己屏幕上的。

```text
/Users/你的用户名/……/fullstack-from-zero
```

`pwd` 是 print working directory 的缩写，意思是“打印当前所在的目录”。目录就是文件夹。

#### 2. 这里有什么：`ls`

```zsh
ls
```

你应该看到这个文件夹里的东西，排成几列（「你的会不一样」：排成几列要看窗口多宽；你的列表可能多几项或少几项，比如课程以后多出来的文件也会列出来）：

```text
CHANGELOG.md		ROADMAP.md		learner
CLAUDE.md		STANDARDS.md		notes
GLOSSARY.md		cheatsheets		stages
LICENSE			docs			starter
LICENSE-CC-BY-4.0.txt	gates			templates
LICENSE-MIT-0.txt	handbook		tools
README.md		journal
```

`ls` 是 list 的缩写，意思是“列出来”。

#### 3. 看另一个文件夹里有什么

先猜一猜：第 3 站要用的小程序放在 `starter/hello-fx` 里，你觉得里面有几个文件？

`ls` 后面空一格，写上一个文件夹的路径，就列出那个文件夹里的东西：

```zsh
ls starter/hello-fx
```

你应该看到：

```text
convert.py	rates.txt
```

`starter/hello-fx` 的意思是“`starter` 文件夹里面的 `hello-fx` 文件夹”。

#### 4. 故意敲错一个字母

把 `pwd` 多敲一个 `d`：

```zsh
pwdd
```

你应该看到：

```text
zsh: command not found: pwdd
```

> 读懂这句：zsh 说，找不到叫 pwdd 的命令。

这就是一条**报错（error message）**：程序告诉你它没办成、卡在哪里的那段话。**zsh** 是在终端里接你命令、照着执行的那个程序，这类程序叫 **shell**（中文有时叫命令解释器）。读报错，先问三个问题：

1. **谁在报错？** 开头写着 `zsh:`，是 zsh。
2. **关键词是什么？** `command not found`，找不到命令。
3. **我刚才敲了什么？** `pwdd`，和课文里的 `pwd` 对照，多了一个 `d`。

三个问题答完，错在哪就清楚了。敲的和课文看着一模一样，却还是报错：多半混进了中文输入法打出来的空格或标点，切到英文输入法，把这一行重敲一遍。

> **旧教程提醒**：老的 Mac 教程是按 bash 这个 shell 写的，提示符印成 `$`；自 macOS 10.15 起，Mac 默认的 shell 换成了 zsh（Apple 支持文章 102360），所以你的提示符以 `%` 结尾。命令前印 `$` 表示提示符，这种写法现在仍然通行，Mac 自带的命令手册也这样印；GitHub 自己的文档写作规范则要求不印（核对日期 2026-11-20）。不管印的是 `$` 还是 `%`，都不要把它敲进去。

#### 5. 停不下来时按 Ctrl+C

故意敲一个只有半边引号的命令：

```zsh
ls "starter
```

终端不会出结果，而是换成一个新的提示：

```text
dquote>
```

> 读懂这句：dquote 是 double quote（双引号）的缩写，意思是“还差一个双引号，我在等你把它补上”。

新手常在这里卡住，敲什么都没反应。按住 Ctrl 再按 C（写作 Ctrl+C），终端就放下这一行，回到 `%` 提示符。〔建课时无法验证〕

记住这一招：终端里停不下来、退不出去，先按 Ctrl+C。以后会遇到例外（比如翻页看长内容时按 q 退出），到那一课再讲。

#### 6. 清屏：`clear`

屏幕上的字太多了：

```zsh
clear
```

`clear` 就是英文的“清除”。屏幕被清空，只剩一行新的提示符；往上滚多半也找不回旧内容。〔建课时无法验证〕屏幕上有还想留着的报错，先复制下来（比如发给导师），再清屏。

## 第 3 站：运行并改动一个小程序（约 25 分钟）

### 概念

**程序（program）** 就是一份写着一步步指令的文本文件。它自己不会动，要交给一个**解释器（interpreter）** 去读、去照着执行。这一站的解释器是 `python3`。

这像菜谱和厨师：`convert.py` 是菜谱，`python3` 是照着菜谱做菜的厨师。这个类比在一个地方不成立：厨师看到菜谱上的错字会自己变通，`python3` 不会，菜谱上错一个符号它就停下来报错。

Python 是这份文件所用的编程语言的名字，`python3` 是电脑上运行它的命令。这一站不学 Python 的写法，只做三件事：运行它，改一个数，再运行，看结果跟着变。

### 跟我做

这一站也在学习工作区里做（提示符里显示 `fullstack-from-zero`）。

#### 1. 运行程序

先猜一猜：这个程序要把 100 美元按 1 美元换 7.10 人民币来换算，它会打印出多少人民币？

```zsh
python3 starter/hello-fx/convert.py
```

你应该看到：

```text
100 美元 ≈ 710.00 人民币（按 1 美元 = 7.10 人民币计算）
```

这条命令的意思是：请 `python3` 去执行 `starter/hello-fx` 文件夹里的 `convert.py` 这个文件。

> **旧教程提醒**：很多教程写的是 `python 文件名`（不带 3）。很多 Mac 上根本没有叫 `python` 的命令，Apple 自 macOS 12.3 起就把老的 Python 2 删掉了。本课程一律写 `python3`。

#### 2. 故意把文件名敲错

```zsh
python3 starter/hello-fx/convrt.py
```

你应该看到（「你的会不一样」：引号里是这个文件的完整路径，中间那几段每台电脑不同）：

```text
python3: can't open file '/Users/你的用户名/……/fullstack-from-zero/starter/hello-fx/convrt.py': [Errno 2] No such file or directory
```

> 读懂这句：python3 说，打不开文件 '……/convrt.py'；[错误编号 2] 没有这个文件或文件夹。

用报错三问读它：

1. **谁在报错？** 开头是 `python3:`，这次是 python3，不是 zsh。命令本身被认出来了，python3 已经开始干活。
2. **关键词是什么？** `can't open file`（打不开文件）和 `No such file or directory`（没有这个文件或文件夹）。
3. **我刚才敲了什么？** `convrt.py`，课文里是 `convert.py`，少了一个 `e`。

这就是本课的行规 **META-01 报错三问**：看到报错，先答这三问，再决定自己改还是求助；求助时把三个答案和报错原文一起发给导师。导师也会先问你这三问，再给提示。

#### 3. 用编辑器打开它

**编辑器（editor）** 是写代码和文档用的软件，本课程用的编辑器是 VS Code（还没装的，照 README「怎么拿到这门课」装）。`code` 命令（VS Code 名字里的 Code）让 VS Code 打开一个文件：

```zsh
code starter/hello-fx/convert.py
```

VS Code 会弹到前面，打开这个文件。终端里通常什么也不显示，直接回到提示符。〔对照文档，界面可能不同〕

VS Code 可能先弹出一个对话框：

```text
Do you want to allow untrusted files in this window?
```

> 读懂这句：要不要在这个窗口里打开不受信任的文件？

这个提示叫工作区信任（Workspace Trust）：对来路不明的文件，VS Code 先多问一句，免得里面的东西自动运行。这里的“工作区”是 VS Code 自己的说法，指这个窗口打开的东西，和学习工作区不是一回事。这个文件是课程自带的，点 **Open**（打开）。点成了 **Open in Restricted Mode**（用受限模式打开）也没关系：会多开一个窗口，照样可以改文件、保存。〔对照文档，界面可能不同〕

终端里提示 `zsh: command not found: code`？用报错三问读一遍，然后对导师说“急救：code 命令找不到”。

#### 4. 改汇率，保存，再运行

文件里大部分是给人看的说明。找到这两行（第 7、8 行）：

```python
AMOUNT_USD = 100  # 要换算的金额，单位是美元
USD_TO_CNY = 7.10  # 1 美元换多少人民币。这是一个示例数字，不是真实汇率
```

每一行是：一个名字、等号、一个数。`#` 后面是说明，程序不管它。

先猜一猜：把第 8 行的 `7.10` 改成 `7.20`，再运行，会打印什么？

在 VS Code 里把 `7.10` 改成 `7.20`，只改数字，别动其他字符。然后按 Cmd+S（键帽上印着 ⌘ command；课文以后写 ⌘S）保存。VS Code 顶上每个打开的文件占一个小格子，叫标签页（tab）。保存之前，标签页上文件名旁边有一个圆点，表示改了还没存；圆点消失，才算存好。〔对照文档，界面可能不同〕

回到终端，再运行这一条：

```zsh
python3 starter/hello-fx/convert.py
```

不用重敲：按 ↑ 键（可能要按几次），直到出现这一行，再按回车。〔建课时无法验证〕你应该看到：

```text
100 美元 ≈ 720.00 人民币（按 1 美元 = 7.20 人民币计算）
```

结果变了，因为 `python3` 每次都重新读这个文件、照着执行。结果没变？多半是没保存：回 VS Code 看那个圆点。

> **改乱了怎么办**：
> 1. 文件还在 VS Code 里开着：按 ⌘Z（撤销）一步步退回改之前的样子，再按 ⌘S 保存。〔对照文档，界面可能不同〕
> 2. 已经关掉了，或者撤销不回去：运行 `python3 tools/course.py scenario 0.1`。工具会在**练习场（playground）**里放一份原版，那是工具专门放练习材料、弄坏了也不要紧的文件夹（`~/Developer/playground`）；它打印的位置开头的 `~` 代表你的主文件夹，第 0.2 课细讲。用它打印的 `code ……` 那一行打开原版，对照着把你的文件改回来；它打印的“接下来”那两步现在不用管（里面的 `cd` 是换文件夹的命令，第 0.2 课学）。你自己的文件，工具不会去碰。
> 3. 还是不行：对导师说“急救：convert.py 改坏了”。

我把金额改成 ______ 以后（汇率是 7.20），我预测程序会打印“______ 美元 ≈ ______ 人民币”。

## 收尾（约 10 分钟）

1. 全课检查（在学习工作区里运行）：`python3 tools/course.py check 0.1`
2. 行规笔记：运行 `code notes/my-rules.md`，在小标题「META-01 报错三问：谁在报错，关键词是什么，我刚才敲了什么」下面用自己的话写一两句，再配一个你自己的例子，写完按 ⌘S 保存。
3. 一句话日志：`python3 tools/course.py journal`

   它一项一项问你，每项敲一句话按回车。第一项“做了什么”要写一句；后面几项有就写一句，没有就直接回车。你会看到类似这样（冒号后面是你自己敲的字；「你的会不一样」：日期）：

   ```text
   做了什么（一句话）：第一次上课：认识了终端，改了小程序的金额
   卡在哪（没有就直接回车）：把 convert.py 敲成了 convrt.py
   下次从哪开始（直接回车 = 从 0.2 开始）：
   哪里看不懂（可选，直接回车跳过）：
   哪里太慢（可选，直接回车跳过）：
   已记到 journal/2026-11-20.md。
   下次打开终端，运行 python3 tools/course.py 就能看到从哪继续。
   ```

   有了“卡在哪、下次从哪开始”，下次坐下来一分钟就能接上。日志一天一个文件，存在 `journal/` 里；工具只往后添，不改你写过的。
