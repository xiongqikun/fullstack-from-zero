# 0.1 的行规

### META-01 报错三问：谁在报错，关键词是什么，我刚才敲了什么

- **约束力**：必须（适用范围：本课程）
- **规则类型**：规范·本课程约定
- **规则**：看到报错先别慌、别重敲：先回答三个问题，谁在报错（哪个程序），关键词是什么（报错里最要紧的那几个英文词），我刚才敲了什么（和课文逐个字符对照）。答完再决定自己改还是求助；求助时把三个答案和报错原文一起发出去。向导师求助之前先答这三问，导师也会先问你这三问，再给提示。
- **谁说的**：本课程的建课计划 `docs/plans/2026-11-19-batch-1-plan.md`（I1 节“报错三问”，2026-11-19 版）。依据：Python 官方教程第 8 章《错误和异常》（Python 3.15.2 文档，2026-11-20 重新打开核对）说，报错的最后一行指出发生了什么，前面给出文件名和行号，告诉你去哪里找 https://docs.python.org/3/tutorial/errors.html
- **核对日期**：2026-11-20；**复核周期**：12 个月，或者 zsh、Python 的报错格式明显改变时
- **谁来管**：导师（本课程）；**不遵守的后果**：只会把报错整段丢给别人或乱试，同一个错下次还是认不出来。
- **为什么**：报错是程序在告诉你它卡在哪里，大多数时候答案就写在里面。三问把一大段英文缩成三件事：谁说的、说了什么、你做了什么。新手的报错多半出在第三问：多一个字母、少一个空格、全角标点。
- **正例**：

      报错：python3: can't open file '/Users/你的用户名/…/starter/hello-fx/convrt.py': [Errno 2] No such file or directory
      谁在报错：python3
      关键词：can't open file、No such file or directory（打不开文件，没有这个文件）
      我刚才敲了什么：convrt.py，课文里是 convert.py，少了一个 e

- **反例**：看到一大段英文，直接把整屏截图发给导师，只写一句“又出错了”；或者不看报错，换着法子把命令重敲五遍。
- **怎么检查**：复习时会再考到它（`python3 tools/course.py review`）；人工检查：求助时你发出的消息里有没有这三个答案和报错原文。
- **例外**：报错里说“检查器出问题”或“这不是你的错”时，不用答三问，直接把那一段发给导师（这时是工具的问题，导师按急救处理）。
- **旧教程提醒**：无
- **学于**：0.1
