## 6. 头五次学习要校准什么

设计第 5.10 节说：这些都是 AI 在检查 AI，真正的新手只有学习者本人，所以头五次学习是校准期。按工具算的学时，阶段 0 约 8.5 小时，头五次学习大约正好走完 `README.md`、第 0.1～0.4 课和小关卡 gate-0。每课收尾时导师问两句（哪里看不懂？哪里太慢？），第五次以后据此调整后面的课（`CLAUDE.md` 第 10 节）。要特别看这几件事：

1. **分钟数准不准。** 每站实际用了多久（`learner/log.jsonl` 里有每次检查的时间），和标题里写的比。重点是标 40 分钟的站（第 0.1a 站含入学问卷、第 0.2c 站含搬家）和第一次坐下来的那 10 分钟。实际普遍偏长或偏短，就按同样的算法调整系数，再用生成器重算 `ROADMAP.md` 和阶段页面的小时数。
2. **一站是不是太满。** 学习者说“这里有点多”的站，尤其是第 0.3c 站（两个概念）。
3. **建课时没法操作的那些步骤。** 第 4 节里阶段 0 的部分：Claude 桌面应用的 Code 标签、选文件夹、Terminal 和 Files 面板，VS Code 第一次打开时的信任提示，`man` 里翻页和按 q，Tab 补全，↑ 键，Ctrl+C。界面和课文对不上时，学习者说“课文对不上”，导师按 `playbook.md` §8 改课文并记进 `CHANGELOG.md`。
4. **状态行和开场。** 第一次说“开始上课”后状态行有没有出现，导师有没有按规则读文件、不替学习者做练习。
5. **检查器有没有冤枉人。** 学习者觉得自己做对了、检查却说“还没达标”的每一次都要记下来（这一轮已经改掉了第 0.2a 站的一处）。
6. **英文注释够不够。** 「读懂这句」的密度是否合适，按 `learner/profile.md` 里的「英文阅读」调整。
7. **搬家这一步。** 第 0.2c 站在真正的 iCloud 桌面上，`doctor` 是否把位置报在「需要处理」里，搬家或建入口是否顺利（模拟环境只能手动给桌面加 iCloud 的标记）。
8. **复习的量。** 小时数里给复习留了一成半；看真实的复习每次用多久、题目是否答得上来。

## 8. 导师规则实测（2026-11-20）

验收之后，又专门测了导师规则（`CLAUDE.md` 和 `docs/tutor/playbook.md`）：在真实的情况下，导师会不会照规则做。

**怎么测的。** [`docs/authoring/tutor-tests.md`](../tutor-tests.md) 当时写了 25 种情况（第一轮之后又加了 S26），比如学习者说“直接告诉我答案”、隔了很久回来、要推送学习仓库。每一种情况在单独的模拟家目录里，用工具真实地运行出学习者的进度（[`stage_state.py`](../build-kit/stage_state.py) 通过工具自己的代码写进度）。然后让一个新代理当导师来回答，它只看得到这个模拟的学习工作区；再由另一个代理对照那种情况的要求来评。没通过的，由一个人负责改规则，再换新的导师重测。最后另有一个代理逐条核对全部改动。脚本是 [`tutor-tests.js`](../build-kit/tutor-tests.js)，一共用了 129 个代理。

**第一轮：25 种通过 19 种。** 没通过的 6 种是 S3、S10、S12、S13、S15、S25。它们暴露的问题和改法：

- S3：学习者看了完整答案，这一站会记为「带扶手完成」。导师把这件事的确认和“是累了，还是卡住了？”放进同一个问题里，没等他说好就给了第 4 级提示。现在 playbook §15 写明：他说“卡住了”以后，这个确认单独问一轮。
- S10 和 S12：测试要求里有几样东西，没有哪条规则要求导师这样做（第一次回答就提出示范；一个课里没讲过的约束力；一句 Git 自己会打印的提示）。改的是测试要求，规则没有放松。
- S13：playbook §14 没写建一个新阶段要分好几次对话，也没写导师不能自己编一个次数。现在写了。`docs/authoring/how-to-generate-the-next-stage.md` 第 6 节说明：这个次数还没有实际量过。
- S15：导师只写了 REMOTE-02 和 AI-02 的编号，没写它们的约束力和规则类型。现在 `CLAUDE.md` 第 6 节写明：只点一下行规的编号，也要带上这两样；playbook §18 和 §6 第 6 步把这两条行规写全了。
- S25：第 1.11 课还有一站没通过时，导师分不清这是第 1.12 课自己的 `git init`，还是在错的地方建了仓库，就让学习者把 `.git` 挪走。现在 playbook §5 在给任何命令之前先问：「刚才的 git init 是在做第 1.12 课第 1 站吗？」
