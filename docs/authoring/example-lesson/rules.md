### EX-01 练习只在练习场里做

- **约束力**：必须（适用范围：本课程）
- **规则类型**：规范·本课程约定
- **规则**：示例课的练习只在工具搭好的练习场文件夹里做，不碰电脑上别的文件夹。
- **谁说的**：本课程示例课 docs/authoring/example-lesson（2026-11-19 版；这张卡是虚构的，只用来演示卡片格式）
- **核对日期**：2026-11-19；**复核周期**：12 个月，或者练习场的位置改变时
- **谁来管**：没有人；**不遵守的后果**：在真正要用的文件夹里试还不熟的命令，可能改坏或删掉有用的文件。
- **为什么**：练习场可以随时重建，做错了没有任何损失。别的文件夹里的东西坏了，常常没法恢复。
- **正例**：

      cd ~/Developer/playground/99.1-start
      pwd

- **反例**：在主文件夹或桌面上直接试还没用熟的命令。
- **怎么检查**：复习题 99.1-r3；人工检查：动手前运行 `pwd`，看输出是不是以 `~/Developer/playground` 开头。
- **例外**：无
- **旧教程提醒**：无
- **学于**：99.1
