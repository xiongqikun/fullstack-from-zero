## 求职之前要知道的事

- 入门岗位少。美国招聘网站 Indeed 的数据：2026 年第一季度，软件开发类的招聘里，面向入门者的占 4.5%，面向资深者的占 69.3%。
- 各地常用的语言不一样。JetBrains（一家开发工具公司）2025 年的调查：60% 的中国开发者以 Java 为主要语言，全球是 28%。本路线的 Python 加 TypeScript 组合是国际上的主流；目标如果是在某个具体地区求职，进入阶段 4 之前要核对当地常用的语言。
- 招聘方对新人的普遍期望，比如能独立走完分支和合并请求、会测自己的改动并说清怎么测的、卡住了早说，在课程里标成“岗位期望”。它们是面试官和团队的要求，不是法律义务。

你如果在中国大陆上网，还会多出几件事：软件下载源、代码托管网站、网站上线的手续都可能要换做法。第 0.1 课的入学问卷会问到，需要时单开一个分支。

## 技术清单（现在看不懂没关系）

- 求职：《Hello 算法》（https://github.com/krahets/hello-algo ，中文，在线免费；它的网站对自动访问返回 429，请用浏览器打开）；LeetCode 式的练习；中文面试材料常说的“八股”。岗位期望的完整列表：`standards-landscape` 调研简报第 5.2 节（Dropbox IC1、SFIA 9 第 2 级等）。
- 研究代码：hidden state 与 Restart & Run All；`src/` 布局；known-answer test；look-ahead bias 与 future-perturbation test；`tomllib` 配置加 `argparse` 命令行；`manifest.json` 与实验日志；`*.meta.json` 加 SHA-256；nbstripout 或 jupytext；pandera。参考：The Good Research Code Handbook（https://goodresearch.dev/ ，英文）、The Turing Way（https://book.the-turing-way.org/ ，英文）。
- AI 功能：调用模型 API、离线评估集、成本预算、OWASP Top 10 for LLM Applications 2025（https://genai.owasp.org/llm-top-10/ ）。
- 开源：《开源软件指南》（https://opensource.guide/zh-hans/ ，中文）。
- 靶场：OWASP Juice Shop（https://owasp.org/www-project-juice-shop/ ）、PortSwigger Web Security Academy（https://portswigger.net/web-security ，英文）。
- 元框架：Next.js（https://nextjs.org/docs ）。
- 进阶阅读：Teach Yourself Computer Science（https://teachyourselfcs.com/ ，英文）；《设计数据密集型应用》第 2 版的社区中文译本（https://ddia.vonng.com/ ）；CS 自学指南（https://csdiy.wiki/ ，中文）。
- 中国大陆环境：PyPI 与 npm 镜像、国内代码托管、域名备案。这些在建课时没有核实，开分支时再查。
