# 0002 先学 Python，再学 JavaScript 和 TypeScript

> **状态**：已采纳（accepted）｜ **日期**：2026-11-19 ｜ **谁定的**：Claude 替你定的技术细节，错了由它负责改 ｜ **征求过意见**：资深工程师评审

## 背景和要回答的问题

全栈（full-stack）的意思是：从用户看得见的界面，到服务器（server，一直开着、替别人干活的电脑）上的程序和数据，都能自己做。这至少要会两门编程语言（programming language，人写给电脑看的指令所用的语言）。浏览器里的网页只认 JavaScript 这一门；服务器上的程序可以用很多种语言写。两门不能同时起步。要回答的是：第一门学哪个？

## 考虑过的方案

* 甲：先学 JavaScript。多数教做网站的免费课程走这条路：一门语言前后都能用，很早就能在浏览器里看到结果。
* 乙：先学 Python，到阶段 6 再学 JavaScript，随后学 TypeScript（在 JavaScript 上加了一层检查的语言，很多错误在运行之前就能查出来）。
* 丙：先学 C 语言。这是哈佛大学入门课 CS50 的做法。它离你要做的网页产品最远，这里没有细比。

## 决定

选乙。建课前的调研没有找到对照研究（controlled study，把人分成两组、只改一个条件来比较的研究）比较过成年人学全栈时先学哪一门更好；调研的结论是教法比语言重要。对你起决定作用的是三件实际的事：这门课的学习工具是用 Python 写的，学这门课本来就要有它（Mac 的命令行开发者工具里就带着 `python3`）；后面写后端（back end，在服务器上干活、不露面的程序）计划用 Python；Python 这边检查代码、跑测试的工具是成套的，JavaScript 那边相对零散。

### 后果

* 好处：阶段 2、3 学的编程和规范，到阶段 5 写后端时接着用同一门语言。
* 代价：要多学一门语言。调研估计，在 Python 之后学 JavaScript 约需 60～100 小时。资深工程师评审（建课前给第 1 版设计挑错的五份意见之一）估计，这条路比只学 JavaScript 多花 100 小时左右，并认为这仍然是对的选择。
* 代价：用 Python 写的东西不会出现在浏览器里。你自己写的、带数据的网页要等到阶段 6。补救见记录 0003：阶段 1 就先把一个手写的网页放到网上。
* 什么时候重新考虑：如果你的目标变成在某个具体地区求职，进入阶段 4 之前要核对当地常用的语言。这套组合在国际上是主流，但各地并不一样。

## 技术清单（现在看不懂没关系）

* 先例。先 JavaScript：The Odin Project、freeCodeCamp、MDN、Scrimba、100Devs、roadmap.sh。先 Python 或先后端：CS50（C → Python → SQL → 网页 → Flask）、赫尔辛基大学的课程链、boot.dev。出处：调研简报 fullstack-curricula 第 0、3 节。
* “没有对照研究”“教法比语言重要”“60～100 小时”：同一份简报第 4 节。它引用的几项语言对比研究只读到摘要一级，60～100 小时是简报作者自己的估计。
* 使用面：Stack Overflow 2026 开发者调查，JavaScript 62.0%、SQL 58.4%、Python 58.0%、TypeScript 43.8%。出处：https://survey.stackoverflow.co/2026/technology ，2026-11-19 核实。
* 地区差异：JetBrains 2025 年的数据里，60% 的中国开发者以 Java 为主要语言，全球是 28%（同一份简报第 0 节第 14 条）。“求职前重新核对”出自资深工程师评审第 20 条。
