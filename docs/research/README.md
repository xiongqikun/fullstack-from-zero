# 调研与评审存档

> 这些简报写于 2026-11-19，那时课程文件夹还叫 `Engineering`。简报里的 `Engineering` 和 `~/Developer/Engineering`，就是现在的 `fullstack-from-zero` 和 `~/Developer/fullstack-from-zero`（2026-11-21 改名）。

这个文件夹不是课文，你不需要读。它是这套课程的"证据柜"：建课之前做的调研笔记。课文里写着"核对于 2026-11-19"的事实，大部分出处在这里；设计文档第 1 版的五份模拟评审没有公开。

以后生成新阶段、或者有人怀疑某条规范是否过时，从这里查起。

## 里面有什么

| 位置 | 内容 |
|---|---|
| `*.md`（21 份） | 各专题的调研简报，英文为主。每条结论都标了依据：`[local]` 表示在建课用的电脑上实际运行过，`[source: 网址]` 表示当天读过原始出处，`[memory]` 表示没能核实 |
| 模拟评审（未公开） | 设计文档第 1 版的 5 份模拟评审：能不能照着建出来、零基础的人看不看得懂、资深全栈工程师、教学设计、"半年后失败了会是因为什么"。这几份模拟评审没有公开 |
| `local-only/` | 只在建课的电脑上、不公开的笔记 |

## 三点说明

- **日期。** 全部内容核对于 2026-11-19；个别出处是 2026-11-20 补核的，就地写了日期。工具和规范会变，引用前先看日期。
- **隐私。** 存档时已经把用户名、邮箱、电脑名替换成了 `<user>`、`<email>`、`<host>`。对私人项目的测量不公开，只放在 `local-only/`；仓库的 `.gitignore` 会把这个文件夹排除在外，不会被推送到 GitHub。
- **这些是笔记，不是规范。** 规范以 `STANDARDS.md` 和 `handbook/` 为准。
