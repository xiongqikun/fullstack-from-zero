## 旧教程提醒

> **旧教程提醒**：老的 Mac 教程是按 bash 这个 shell 写的，提示符印成 `$`；自 macOS 10.15 起，Mac 默认的 shell 换成了 zsh（Apple 支持文章 102360），所以你的提示符以 `%` 结尾。命令前印 `$` 表示提示符，这种写法现在仍然通行，Mac 自带的命令手册也这样印；GitHub 自己的文档写作规范则要求不印（核对日期 2026-11-20）。不管印的是 `$` 还是 `%`，都不要把它敲进去。（第 0.1 课）

> **旧教程提醒**：很多教程写的是 `python 文件名`（不带 3）。很多 Mac 上根本没有叫 `python` 的命令，Apple 自 macOS 12.3 起就把老的 Python 2 删掉了。本课程一律写 `python3`。（第 0.1 课）

> **旧教程提醒**：照着 Linux 写的教程常用小写的 `cp -r`。在 Mac 上请用大写的 `-R`：Mac 自带的 `man cp`（macOS 27.2，2025-09-02 版，2026-11-19 核对）写着，`-r` 是历史遗留的选项，各系统行为不一样，强烈不建议用。（第 1.2 课）
