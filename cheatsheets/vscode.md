# VS Code 速查

> 只收阶段 0～1 用到的操作。终端里的 `code` 命令 2026-11-19 在模拟环境里核对过；VS Code 窗口里的操作建课时没法点，是对照 VS Code 1.145.2 的官方文档写的，全都算〔对照文档，界面可能不同〕。VS Code 现在每周更新，按钮会挪，记功能的名字，不记按钮的位置。
> 按键符号：⌘ 是 Command 键，⇧ 是 Shift 键，⌃ 是 Control 键。⇧⌘P 就是按住 Shift 和 Command，再按 P。

## 从终端打开

| 命令 | 做什么 | 哪一课 |
|---|---|---|
| `code <文件>` | 用 VS Code 打开一个文件（比如 `code notes/my-rules.md`） | 0.1 |
| `code .` | 打开我现在所在的整个文件夹：做项目时都这样开（ED-01） | 1.4 |
| `open index.html` | 用默认的浏览器打开网页；改完保存，在浏览器里按 ⌘R 刷新 | 1.4 |

和你看到的不一样？把屏幕上的内容发给导师，说“课文对不上”。

## 信任提示

| 你看到的 | 意思 | 怎么做 | 哪一课 |
|---|---|---|---|
| `Do you want to allow untrusted files in this window?` | 要不要在这个窗口里打开不受信任的文件（工作区信任，Workspace Trust） | 课程自带的文件点 **Open**；点成 **Open in Restricted Mode** 也照样能改、能存 | 0.1 |
| 顶上一条 `Restricted Mode is intended for safe code browsing.` 横幅 | 受限模式：能看能改，但不替你运行文件夹里的任何东西 | 课程工具搭的文件夹：点 `Manage`，再点 `Trust`。网上下载的、别人发来的，先别信任 | 1.4 |

## 一个项目的格式约定（第 1.4 课）

项目根目录放一份 `.editorconfig`，写明 UTF-8、LF 换行、缩进几格（ED-02）。VS Code 要装 EditorConfig 扩展才会照它做；不装，`.editorconfig` 也照样是给人和其他工具看的约定。

## 旧教程提醒

> **旧教程提醒**：以前（1.57 版起，2021 年）打开新文件夹时，VS Code 会先弹出一个对话框问你信不信任；现在新文件夹先在受限模式里打开，只显示这条横幅，由你决定（自 1.126 版，2026-06-24 起，设置 `security.workspace.trust.startupPrompt` 的默认值从 `once` 改成了 `never`）。（第 1.4 课）

> **旧教程提醒**：以前 VS Code 大约每月更新一次，教程截图能用很久；现在每周发一个稳定版（自 1.111 版，2026-03-09 起），按钮的位置常常挪动。所以这门课教你记功能的名字（在命令面板里搜），不教你记按钮在屏幕上的位置。（第 1.4 课）
